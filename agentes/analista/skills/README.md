Las reglas de `agentes/README.md` mandan sobre las skills. Donde una skill sugiera leer el texto de una conversación (por ejemplo, el fallback a `n8n_chat_histories`), quedate con los conteos.

Las otras skills de `.grok/skills/` (`suplai-jefe-linear`, `suplai-catalogo-novedades`, `suplai-probador-whatsapp`) son del plantel viejo y el Analista no las usa.
